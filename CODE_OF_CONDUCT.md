# Code of Conduct

This project adopts the Contributor Covenant Code of Conduct 2.1.

## Our Standards

Examples of behavior that contributes to a positive environment:

- giving and receiving technical feedback directly and respectfully
- assuming good intent while still holding a high engineering bar
- documenting tradeoffs clearly
- prioritizing reproducible evidence over rhetoric

Examples of unacceptable behavior:

- harassment, intimidation, or personal attacks
- bad-faith reviews or deliberately misleading technical claims
- publishing private information without permission
- disruptive behavior that prevents maintainers or contributors from collaborating effectively

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing this Code of Conduct and may remove, edit, or reject comments, commits, code, issues, and other contributions that are not aligned with it.

## Scope

This Code of Conduct applies in all project spaces and in public spaces when an individual is representing the project or its community.

## Reporting

Report incidents privately through GitHub to the project maintainer. Do not open public issues for conduct incidents.
